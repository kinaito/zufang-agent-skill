# 智能体异常排查与自愈决策树（ERROR_SOP）

> **说明**：本表汇集了在真实租房监控环境中踩过的所有核心坑点与异常场景。  
> 任何智能体在执行任务遇到报错或阻碍时，**严禁自行推测或盲目重试**，请直接按照本表对应的场景与自愈策略进行处理。  
> ⚠️ **重试熔断铁律**：任何自愈操作**最多重试 2 次**，若重试 2 次仍未恢复，必须立即升级向人类求助，严禁陷入死循环！

---

## 异常速查与决策矩阵

| 错误类别 | 错误现象 / 日志关键词 | 根本原因 | 智能体固定动作 (Action for Agent) | 是否打扰人类 |
| :--- | :--- | :--- | :--- | :---: |
| **设备连接** | `device unauthorized` / `no devices/emulators found` | USB 调试未开启或电脑未获授权 | 1. 运行 `adb devices`<br>2. 提示用户：“检测到手机未授权，请点亮手机屏幕并勾选【一律允许使用这台计算机进行调试】。” | 是 |
| **设备连接** | `adb server version doesn't match` | 本地 adb 服务版本冲突 | 运行 `adb kill-server && adb start-server` 重启 adb 后重试（最多1次）。 | 否 |
| **设备状态** | `UiObjectNotFoundError` / 无法定位任何控件 | 手机处于息屏或锁屏状态 | 1. 执行 `adb shell input keyevent 224` (唤醒屏幕)<br>2. 执行 `adb shell wm dismiss-keyguard` (解锁)<br>3. 重新运行 `python3 agent_pack/cap.py doctor` | 否（若有密码则提示用户解锁） |
| **页面迷失** | 误入广告页 / 房源详情页 / 经纪人微聊 | 滑动列表或点击卡片时误触了非预期区域 | **视觉看门狗自愈**：Dump UI 识别包含 `房屋简介`/`在线咨询`/`费用明细` 时，按 1 次 `back` 原地返回列表。 | 否 |
| **页面迷失** | 误退回【租房频道首页】或【App 总首页】 | 连续按 back 导致退层过深 | 1. 若在租房首页（含`地图找房`/`我要出租`）：点击【查看房源】按钮进入列表；<br>2. 若在 App 总首页（含`二手房`/`你想住在哪？`）：点击【租房】金刚位图标进入。 | 否 |
| **页面迷失** | 误入【选择城市页】或完全迷失位置 | 点击了城市选择组件或位置错乱 | **逐级回退法**：逐级按 `back`，直到视觉识别出 App 总首页的【租房】金刚位，重新进入租房列表。 | 否 |
| **页面迷失** | 多轮回退仍无法恢复（终极死锁） | App UI 状态彻底卡死 | **终极冷启动重启**：<br>1. 强杀 App：`d.app_start('com.homelink.android', stop=True)`；<br>2. 预留 ≥5 秒等待开屏全屏广告；<br>3. 若有广告点击右上角【跳过】；<br>4. 在 App 总首页点击【租房】重新导航。 | 否 |
| **筛选控制** | 误选到【禅城】或商圈多选残留 (`商圈(2)`) | 点击【重置】后行政区被默认重置回禅城 | **严格单选 SOP**：打开 Tab 1 -> 点击【重置】-> 显式点击【南海】-> 视觉断言第 3 列出现南海商圈 -> 在第 3 列单选目标商圈 -> 点击【查看房源】-> 视觉核验顶部 Tab 1 严格等于目标商圈名。 | 否 |
| **反爬对抗** | 界面弹出滑块验证码 / `安全验证` / `操作过于频繁` | 触发了链家/贝壳风控检测 | **严禁写脚本强破**。立即向用户输出提示：“采集触发了链家安全滑块验证，请在手机屏幕上按提示手动滑过验证码，完成后告知我继续。” | 是 |
| **反爬对抗** | `navigator.webdriver=true` / CDP 访问被 403 拦截 | 链家 WAF 拦截了自动化无头浏览器 | 放弃 PC 无头抓取模式，转为使用安卓真机 UI 控件树采集方案（`cap.py acquire`）。 | 否 |
| **抓包通信** | `SSL Pinning` / `MITM 抓包无数据` | 贝壳客户端做了证书绑定，不信任中间人 CA | 微信小程序/APP 抓包已证明不可行，使用安卓真机 UI 控件树方案。 | 否 |
| **数据采集** | 详情页未能提取到 `FS...` 编号 | 网络延迟或页面卡顿未加载完详情 | 脚本已自动跳过该房源并记录 Warning，无需人工介入，下轮扫描自动重试。 | 否 |
| **数据采集** | 面积字符匹配失败 / `NoneType` 导致正则崩溃 | 链家使用了特殊 Unicode 平方米字符 `㎡` (`\u33a1` vs `\u33a2`) | 使用兼顾正则 `r"(\d+(?:\.\d+)?)\s*(?:㎡|m²|平米)"` 进行解析提取。 | 否 |
| **UI 自动化** | 点击卡片误触底部“行情浮层”或“广告推广” | 滑动或点击落在了屏幕危险区域 | 严格约束点击坐标在安全区间（`450 <= cy <= 2150`），边缘卡片先滑动至中间再执行点击。 | 否 |
| **UI 自动化** | 列表折叠后商圈搜索栏丢失 | 界面处于深层列表页未返回根目录 | 执行 `adb shell input keyevent 4` (Back键) 直到返回租房主搜索页。 | 否 |
| **地理编码** | 小区在地图上未显示 / `lat/lng 为空` | 新收录小区未生成 GCJ-02 真实坐标 | 运行 `cap.py acquire` 时已自动执行 `geo_fill.py` 补全。 | 否 |
| **版本与UI** | `App 版本不匹配 / UI 结构变动` | 链家 App 自动升级导致 Resource-ID 或布局变更 | **自适应语义探针**：<br>1. 触发 UI Dump，模糊匹配 `text` 或 `content-desc` 包含【租房/筛选/整租】等关键词；<br>2. 若为纯图标，调用本地 OCR 或视觉看门狗定位坐标；<br>3. 记录 `[UI_DRIFT_RESOLVED]` 正常继续，不阻塞任务。 | 否 |
| **地理编码** | `高德/百度 API 额度超限或无 Key` | 用户未配置第三方地图 API Key | **离线字典优先**：自动查阅 `communities.json` 离线库回填经纬度；未收录小区标记为“待定位”并不阻塞主流程。 | 否 |
| **本地服务** | `OSError: [Errno 48] Address already in use: 18888 / 8080` | 上次启动的 server 仍在后台占用端口 | 运行 `lsof -ti:18888 | xargs kill -9` 释放端口后重新执行 `python3 agent_pack/cap.py serve`。 | 否 |

## 异常处置升级阶梯（Three-Tier Escalation）

1. **第 1 阶（自愈）**：尝试本表给出的固定修复命令（如唤醒屏幕、释放端口、重连 adb、UI 树模糊语义重定位、离线坐标回填），静默恢复（最多 2 次）。
2. **第 2 阶（降级）**：单子区域若遇网络超时，跳过该子区域并记录 Warning，继续扫描其余子区域，避免整个流水线阻塞；无坐标房源先展示在列表待定区。
3. **第 3 阶（求助）**：遇物理硬件断开、人机滑块、账号封禁等非算法能解之问题，及时、准确地向人类发出求助，说明**具体需要人类在手机或电脑上按哪一步操作**。
