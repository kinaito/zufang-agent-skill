## 演进记录

### [v1.3.0] - 2026-08-26
- **房源身份指纹（dHash）三阶段去重与重上调价自动继承闭环**：
  1. **三阶段去重架构落地**：
     - **L1 列表硬标签初筛**：排除运营标签（如`7日新上`、`可月付`），仅匹配不可变物理特征（小区、户型、面积、朝向、楼层、电梯、民水民电）；
     - **L2 详情页 FS 快速直判**：FS 相同直接跳过；FS 改变但物理硬标签重合触发 L3；
     - **L3 首屏居室 dHash 终审**：进入详情页确认处于「房间」Tab，截取居室黄金抗噪窗口 `(0, 380, width, 1200)`（避开顶部中介打招呼浮窗 `y<380` 与底部好房装饰横幅 `y>1200`），计算 64-bit dHash。
  2. **判重阈值收敛至 90%（汉明距离 $\le 6$）**：物理硬标签完全一致时，放宽至 90% 相似度，完美兼容钻石/黄金/白银横幅等级升降级与微弱光影变化，且零误判同小区他房。
  3. **状态与历史流水自动继承**：识别为重上房源后，自动在 `relist_info` 中关联旧 FS ID 与原价，无缝继承原 `status`（如「考虑中/已看/排除」）与 `notes`，并向 `statusHistory` 追加调价流水。
  4. **代码与文档全量归档**：更新 [`采集方案/app_crawl_all.py`](file:///Volumes/outspace/project/租房子/采集方案/app_crawl_all.py) 与 [`采集方案/06-房源身份指纹去重方案.md`](file:///Volumes/outspace/project/租房子/采集方案/06-房源身份指纹去重方案.md)。

### [v1.2.0] - 2026-08-25
- **爬虫引擎与筛选机制源头加固**：
  1. **源头 App 级面积精准多选**：在链家 App 条件筛选第 2 项（方式/居室/面积面板）中，自动化复选「100-120㎡」与「≥120㎡」，配合代码层 `MIN_AREA = 100.0` 双重防线，从接口源头剔除 <100㎡ 无关房源，大幅减少无效卡片滑动并杜绝由于小面积断层导致的列表早退；
  2. **多维特征与 Tags 签名加固**：在 `list_signature` 与 `project_signature` 中注入微标签（`tags` 如 `可月付`、`双卫`、`7日新上`）、朝向、楼层区间，支持同小区同面积同价格的不同房源精准识别与入库；
  3. **触底判定防误退**：即使命中推荐分割线，也保持连续空滑多屏确认机制，防止列表中间插播推荐卡片引发早退；
  4. **实机验证成果**：完成【盐步】实机复检与数据加固，全库房源数升至 619 套。

### [v1.1.0] - 2026-08-24
- **修复与代码对齐**：
  1. **彻底根治 FSAPP 伪 ID**：修改 `app_crawl_all.py`，若详情页未能提取到真实有效 `FS...` 编号则直接跳过（Skip）并记 Warning，绝不写入伪 ID 占位；清理历史 10 个遗留 `FSAPP_` 文件与索引。
  2. **废除 Early Stop 残留描述**：清理代码头部注释与文档，明确顺流滑至自然触底机制。
  3. **落地统一 CLI 门面 `cap.py`**：新增 `doctor / acquire / db / report / serve` 五大标准命令，统一输出结构化 JSON 与标准退出码。
  4. **参数透传修复**：在 `cap.py acquire` 中将 `--sub-region` 参数完整透传到底层扫描引擎，支持单商圈或多商圈精准扫描。
  5. **推荐算法升级**：将 `report` 升级为“用户状态（考虑中优先）+ 每平米租金单价（元/㎡）真实性价比”加权推荐，自动过滤已排除房源。
  6. **小模型赋能与沙箱支持**：所有命令输出附带 `next_action` 与单行 `solution_for_agent`；支持 `--dry-run` 零真机依赖协议模拟。
  7. **重试熔断机制**：在 `ERROR_SOP.md` 中确立最多重试 2 次熔断规则，避免弱模型陷入试错死循环。
