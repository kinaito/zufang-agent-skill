# 租房自动化监控与地图管理技能（zufang-monitor）

本技能将真实的房源采集、数据验真、去重调价继承与本地 PC 网页地图管理封装为一套高韧性、具备全自动异常自愈能力的标准化作业流。

---

## 🎯 核心设计哲学

1. **小白零门槛（Zero-Config Entry）**：
   - 优先采用本地离线小区字典（`communities.json`），免除强制申请高德/百度/腾讯地图 API Key 的繁琐流程。
   - 提供双击即用的启动器，任务启动后自动唤起 PC 默认浏览器打开地图与看板。
2. **大屏 PC 优先，零网络心智**：
   - 坚守 PC Web 端的大视野交互，通过本地 `127.0.0.1` 极简 HTTP 服务实现房源状态（收录 / 考虑中 / 已看 / 排除）即点即存。
3. **多级视觉降级体系（UI 树 ➔ OCR ➔ 多模态视觉）**：
   - 首选原生 UI 控件树极速定位；若无文字/纯图片控件则自动调用本地 OCR；模型具备视觉能力时使用截图看门狗判定。
4. **确定性基线 + 临场 UI 漂移自适应探针**：
   - 锁定已验证的链家 App 黄金版本；若检测到用户安装了新版 App 导致 UI 变动，智能体自动启动语义模糊探针进行自适应。
5. **历史踩坑沉淀闭环**：
   - 内置全部历史踩坑防御守则，严禁盲目重试，最大重试次数严格限制为 2 次。

## 🛡️ 智能体六大历史踩坑防御守则（必须严格遵守）

| 守则编号 | 历史踩坑痛点 | 防御与自愈规则 |
| :--- | :--- | :--- |
| **规则 1** | **Unicode ㎡ 字符容错** | 链家使用的 `㎡` 存在不同编码（`\u33a1` 与 `\u33a2`）。提取面积必须使用正则：`r"(\d+(?:\.\d+)?)\s*(?:㎡|m²|平米)"`。 |
| **规则 2** | **严禁伪 ID 污染数据库** | 页面卡顿未提取到真实有效 `FS...` 编号时，**直接 Skip 并记 Warning**，下轮扫描自动重试，**严禁生成伪 ID 占位**。 |
| **规则 3** | **黄金屏幕安全区点击** | 严格限制点击/滑动落在基准中段（`450 <= y <= 2150`），防止误触底部广告浮层或经纪人微聊。 |
| **规则 4** | **连续空滑防假触底** | 列表中间插播“为您推荐”卡片时，必须执行连续空滑多屏确认机制，确认真正触底才切换下一商圈。 |
| **规则 5** | **dHash 指纹去重与调价继承** | 中介重新上架获取新 FS 编号时，通过首屏居室 64-bit dHash（$\ge 90\%$ 相似度）自动继承原状态并追加调价流水。 |
| **规则 6** | **单商圈独立闭环落盘** | 遍历子商圈时，扫完一个商圈即刻落盘索引与坐标。即便中途拔线断开，已有数据 100% 安全。 |

```mermaid
graph TD

    D & F --> G[记录一条 [UI_DRIFT_RESOLVED] 日志继续作业]
```

## ⚙️ 自然语言转配置驱动（全国城市通用解耦）

系统完全由 `agent_pack/config.json` 驱动。当用户提出个性化找房需求（如：“帮我找广州天河东圃 2500 到 4000 的两居室”）时，智能体可直接更新该配置文件：
- `target_city`: 目标城市（如 `广州`）
- `target_district`: 目标行政区（如 `天河`）
- `sub_regions`: 目标商圈列表（如 `[{"name": "东圃"}, {"name": "车陂"}]`）
- `search_criteria`: 租金区间、居室户型、最小面积等

## 📱 屏幕自适应规范（直板屏与非规整屏）
- 系统基于屏幕宽高的相对百分比（`SAFE_TOP_RATIO: 16%`, `SAFE_BOTTOM_RATIO: 77%`）进行滑动与点击安全过滤；
- 主流 16:9 / 18:9 / 20:9 直板屏开箱即用；
- 若使用折叠屏展开态或特殊长宽比屏幕，智能体将依据 `d.window_size()` 动态计算缩放比例 `SX` 与 `SY`，避免误触边缘通知栏或手势导航栏。

## 🚀 标准调度指令集合

智能体在调度任务时，统一调用 `agent_pack/cap.py` 命令行门面：

```bash
# 1. 前置体检与自愈（自动读取目标配置、检查设备状态、App版本）
python3 agent_pack/cap.py doctor

# 2. 执行全量/指定商圈扫描 (根据 config.json 动态驱动)
python3 agent_pack/cap.py acquire --sub-region all
python3 agent_pack/cap.py acquire --sub-region 东圃

# 3. 校验数据库完整性
python3 agent_pack/cap.py db --action summary

# 4. 生成结构化推荐报告
python3 agent_pack/cap.py report

# 5. 启动本地 Web 服务并自动唤起浏览器
python3 agent_pack/cap.py serve --open-browser
```

## 🆘 异常排查与人机协同升级阶梯

遇阻时请查阅 [ERROR_SOP.md](file:///Volumes/outspace/project/租房子/agent_pack/ERROR_SOP.md)：
1. **静默自愈（最多 2 次）**：自动唤醒屏幕、释放占用端口、重启 ADB、回退迷失页面；
2. **容错降级**：单商圈网络超时则跳过继续下一个商圈，坐标获取失败先展示在待定列表；
3. **极简人机协同**：遇滑块验证码或 USB 断开时，向用户输出清晰操作卡片（“请在手机上滑动滑块，完成后回复已搞定”）。
