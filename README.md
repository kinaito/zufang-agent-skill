# 🏠 zufang-agent-skill: 全自动移动端租房监控与智能看板技能

> 🤖 **面向 AI 时代个人的高韧性找房技能**  
> 专为大语言模型智能体（Cursor, Claude, Antigravity, OpenDevin 等）与非技术用户打造。支持全国任意城市、任意户型预算，全自动真机采集、房源调价追踪与本地 PC Web 地图看板流转。

---

## ✨ 核心特性

- 🎯 **全国城市通用解耦**：目标城市、行政区、商圈与租金偏好由 `config.json` 动态驱动，智能体可通过自然语言对话直接修改。
- 📱 **直板与异形屏自适应**：滑动与安全操作区基于屏幕宽高动态百分比计算，告别绝对像素写死，适配各类分辨率。
- 🗺️ **原生经纬度与地图自适应**：房源自带 GCJ-02 真实坐标，PC 网页地图自动根据房源分布缩放居中，全国各地无缝呈现。
- 🛡️ **生产级自愈看门狗**：包含迷失逐级回退、冷启动广告跳过、连续空滑防误退、居室首屏 dHash 指纹去重与调价历史继承。
- ⚡ **小白双击即用**：提供 macOS / Windows 双击启动器，后台静默环境检查并自动唤起默认浏览器打开地图。

## 🚀 极简上手指南（只需两步）

### 步骤一：连接安卓手机并开启 USB 调试
1. 使用 USB 数据线将安卓手机连接到电脑；
2. 开启手机系统的【开发者选项】与【USB 调试】（通常在 `设置 -> 关于手机` 连续点击 7 次“版本号”即可激活）；
3. 手机弹出【允许 USB 调试吗？】时，勾选【始终允许】并点击确定。

### 步骤二：种植“搜索历史锚点”（重要）
1. 在手机上打开一次【链家 App】并登录；
2. 进入【租房】频道，在搜索栏**手动搜索一次你想要找的目标商圈**（例如：**天河**、**海淀** 或 **千灯湖**）；
3. *原理：手动搜索一次可以自然抹平所有新安装 App 的隐私协议与系统权限弹窗，并在历史记录中留下确定性锚点。*

## 🤖 智能体（Agent）驱动方式

如果你使用的是 AI 辅助编码工具（如 Antigravity / Cursor / Claude 等），只需将本仓库作为工作区打开，并直接输入自然语言指令：

> 💬 **指令示例**：  
> *“帮我找广州天河东圃 2500 到 4000 的两居室，开始扫描并在网页上展示。”*

**智能体将全自动执行以下标准流水线**：
1. **自动生成配置**：将你的自然语言转化为 `agent_pack/config.json`；
2. **环境自检自愈**：执行 `python3 agent_pack/cap.py doctor`；
3. **驱动手机扫描**：执行 `python3 agent_pack/cap.py acquire --sub-region all`；
4. **拉起本地可视化**：执行 `python3 agent_pack/cap.py serve --open-browser` 弹出看板。

## 🖥️ 手动 / 独立运行方式

如果你不需要智能体，也可以完全手动独立运行：

### 1. 运行本地地图看板
- **macOS**：直接双击运行项目根目录下的 **`一键找房.command`**
- **Windows**：直接双击运行项目根目录下的 **`一键找房.bat`**
- 浏览器将自动打开 `http://127.0.0.1:18888/map.html`，查看已有房源、切换标记状态（收录 / 考虑中 / 已看 / 排除）。

### 2. 命令行执行体检与抓取
```bash
# 1. 检查运行环境与设备连接
python3 agent_pack/cap.py doctor

# 2. 执行房源采集 (支持指定商圈)
python3 agent_pack/cap.py acquire --sub-region all

# 3. 启动本地服务并弹出浏览器
python3 agent_pack/cap.py serve --open-browser
```

## 🛡️ 历史实战避坑与自愈守则

本技能将作者在实战中踩过的血泪教训全部封装为确定性防线：
1. **Unicode 字符容错**：全面兼容特殊平方米编码（`\u33a1`、`\u33a2`、`㎡`、`m²`），杜绝正则解析崩溃；
2. **零脏数据入库**：未在详情页抓取到真实有效 `FS...` 验真编号直接跳过，严禁伪 ID 占位；
3. **黄金操作区拦截**：严格限定点击与滑动在屏幕高度的 `16% ~ 77%` 中间段，避免误触通知栏或广告横幅；
4. **防假触底连续空滑**：列表中间插播运营推荐卡片时，执行连续空滑多屏校验，确认触底后才切换下一个商圈；
5. **dHash 首屏指纹去重**：中介重新上架换新编号时，首屏居室 64-bit dHash 自动识别并继承历史状态与调价记录。
